### 🧠 Un sistema del que estoy orgulloso

El asistente de voz que opero recibe **llamadas spam constantes**, algo que hace inviable un agente de IA porque cada llamada basura cuesta minutos facturados.

Diseñé una **defensa en tres capas** —filtrado a nivel de telefonía, bloqueo automatizado en n8n y reglas dentro del propio asistente— que contiene las llamadas no deseadas antes de que consuman recursos. Además, el sistema identifica al llamante, filtra por intención y enruta a destinos de respaldo cuando falla un componente.

Resolver eso fue más difícil que construir el agente.
